# Quantitative Methods Portfolio

Applied quantitative and machine-learning analyses in R, drawn from graduate coursework and independent projects in psychology and data science.

I am a Psychology M.A. (NYU, 2026) with applied training in statistical modeling and machine learning, alongside hands-on experimental research experience. This repository collects selected analysis projects that illustrate how I approach a quantitative problem end to end — from data preparation and modeling to validation and interpretation of where and why a model succeeds or fails.

## Projects

**[cart-rf-wvs](./cart-rf-wvs)** — Predicting country of residence from value-survey responses using CART and Random Forest on the World Values Survey (2021). Covers leakage-safe preprocessing, tree pruning via the 1-SE rule, Random Forest tuning, and a direct comparison of where each method fails. *(Graduate coursework, NYU.)*

*Additional projects (confirmatory factor analysis in lavaan; psychometric network analysis) will be added as they are finalized.*

## Notes

These are coursework and independent learning projects, shared to illustrate applied methodology in R. Datasets governed by external usage terms (e.g., the World Values Survey) are not redistributed here; each project's README documents the data source.
